# ADR-0015: Internationalisation: English at launch, ICU message keys from day 1 (D6)

- **Status:** Accepted · 2026-10-30

## Decision
- All UI strings go through `i18next` + ICU MessageFormat (plurals, units). No hard-coded copy in components (an ESLint rule enforces it).
- Launch locale: **en**. The catalogue structure is ready for fr, zh-CN and ru (the reference's set) as a later content task.
- Garment names and cuts are localised in the garment manifest (`Localised` maps).
- Units and numbers use `Intl.NumberFormat`; default unit by locale (en-US → in, others → cm), user-overridable.

## Consequences
Adding a language is translation work only.

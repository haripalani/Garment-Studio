Garment Studio API (1.0.0-draft.1)

Download OpenAPI specification:

License: LicenseRef-Proprietary

Projects, assets, garments, rendering, exports, accounts and entitlements.

Stage 2 draft (contract-first, ADR-0010). Shared by web, PWA and desktop clients.

Conventions

  • All geometry inside documents is in millimetres (ADR-0008).
  • Errors use RFC 9457 application/problem+json with a stable code.
  • Cursor pagination: ?cursor=<opaque>&limit=1..100, response { items, nextCursor }.
  • POSTs that create jobs or consume credits accept Idempotency-Key.
  • Rate limits (ADR-0010) are reported with RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset; exceeding them returns 429.
  • Web clients authenticate with a Bearer access token, refreshed via an HttpOnly cookie; desktop clients use PKCE and send the refresh token in the body (ADR-0011).
